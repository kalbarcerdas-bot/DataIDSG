# Riset 9.6 — Pendidikan Daerah Tambang Bayan

Cut-off: 24 Oktober 2026. Data BPS Tabang 2023/2024, RPJMD Kukar 2020–2024, registry sekolah (snapshot saat riset), kemiskinan/RLS Kukar 2025, PPM Bayan 2022–2025.

Files:
- RESEARCH_REPORT.md — analytic report and definitions
- education_indicators_master.csv — all metrics with source and geographic level
- school_registry_2026_capture.csv — named schools by NPSN, level, village, public/private
- tabang_19_villages_school_presence.csv — 19 villages with school presence and counts
- dapo_residu_data_quality_2025.csv — administrative quality, NOT IQ or learning outcomes
- data_gaps_and_requests.csv — public information request checklist
- source_registry.csv — accessible primary/secondary links and limitations
- validation_checks.json — arithmetic and school counts
- Kalcer_Audit_Pendidikan_Tabang_Kukar_2026.xlsx — structured workbook
- MANIFEST_SHA256.csv — file integrity

Do NOT infer causal attribution to Bayan from district-level data. No child-level personal information included.
