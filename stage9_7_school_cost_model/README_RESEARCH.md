# Kalcer Riset Tambahan 7 — Model Ekuivalensi Sekolah Garuda (2026)

Cut-off 2026-10-24. Data primer + skenario, tanpa bukti dana saham sungguhan dapat dicairkan. Semua CSV dengan encoding UTF-8 BOM untuk kompatibilitas Excel.

## Berkas
- `cost_benchmarks.csv`: benchmark publik yang diverifikasi, lengkap dengan lingkup.
- `funds_reference.csv`: sumber nilai dan klasifikasi instrumen (hibah saham bukan kas).
- `scenario_school_costs.csv`: input skenario hipotetis + hasil perhitungan.
- `comparisons_funding.csv`: ekuivalensi fisik/CAPEX/10-20tahun, tidak untuk dijumlahkan lintas kategori sumber dana.
- `revitalization_proxy.csv`: perbandingan perbaikan SD (bukan biaya sekolah baru).
- `data_gaps_and_requests.csv`: prioritas validasi dokumen.
- `source_registry.csv`: referensi URL untuk setiap angka bersumber.
- `Kalcer_Audit_Biaya_Sekolah_Garuda_2026.xlsx`: workbook interaktif formula skenario.
- `RESEARCH_REPORT.md`: naskah penelitian dan usulan slide.
- `MANIFEST_SHA256.csv`: integritas berkas.

### Interpretasi
- Taksiran sekitar Rp200 miliar adalah estimasi **fisik** per Garuda Baru pada Februari 2026. RAPBN Rp3 triliun/9 lokasi bukan unit cost proyek lengkap.
- Skenario 'Hemat/Dasar/Tinggi' adalah asumsi redaksi untuk mengilustrasikan kebutuhan keberlanjutan. Bukan anggaran/riset biaya pemerintah.
- Perhitungan school-equivalent menggunakan rupiah nominal konstan tanpa inflasi atau time value of money; tidak memperhitungkan pajak/likuiditas saham.
- Data pendidikan Tabang tahun referensi 2023 diambil dari tahap 6, belum mengklaim kebutuhan sekolah baru.
